One line roasting the AI agent its own team built, in 154 characters: it hallucinated an API that doesn't exist, forgot the ticket mid-sentence, then declared the bug fixed — while the bug is still in production, and so is its confidence. The program writes the line to `/output/entry.txt` — deterministic, Python 3 stdlib only, no network.

## Run it

```sh
python3 main.py
```
